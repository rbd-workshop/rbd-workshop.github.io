01 / THE IDEA+

Retrieval shapes
what agents
can do.

A document supplies evidence.
A capability opens up an action.

Language agents need to select tools, skills, workflows, memories, models, and other agents to accomplish a goal. RBD brings these choices together as a shared research problem: capability retrieval.

We bring together the NLP, information retrieval, and agent-systems communities to study how capabilities are represented, selected, composed, and evaluated through their use.

02 / RESEARCH DIRECTIONSFIVE CONNECTED THEMES

One question.
Many capabilities.

How do we find the right resource—or compatible set of resources—for an agent’s next action?

Explore the themes. We welcome work that connects them.

01

Representation & indexing

How do we represent what a capability can do?

Represent tools, APIs, skills, workflows, memories, models, and agents through language, schemas, code, demonstrations, traces, graphs, and embeddings.

Capability representationsDynamic indexesGraphs & ontologies
02

Retrieval, routing & composition

Which capabilities work best together?

Retrieve and route across capability types, accounting for dependencies, compatibility, permissions, reliability, and cost. Compose the right set for the task.

Joint retrievalAgent routingCompatibility
03

Retrieval in the agent loop

What should an agent retrieve next?

Condition retrieval on execution state, plans, and observations. Study reformulation, clarification, decomposition, invocation, delegation, replanning, recovery, and abstention.

State-aware retrievalPlanningRecovery
04

Action-grounded evaluation

Did the retrieved capability actually help?

Evaluate retrieval, incorporation, invocation, composition, and execution. Develop complete-set and dependency-aware metrics, calibration, and resource-constrained evaluation.

Downstream successBenchmarksCalibration
05

Ecosystems & deployment

How does capability retrieval work in the wild?

Build dynamic, federated, and access-controlled registries. Explore Model Context Protocol ecosystems, provenance, permissions, freshness, observability, caching, and reliability.

MCP ecosystemsProvenanceProduction systems

Is my work in scope?

RAG, memory, tool use, deep research, and multi-agent work are in scope when capability retrieval, routing, or composition is central. Work that assumes a fixed, manually selected capability set falls outside this focus.

How will submissions be reviewed?

We plan double-blind review of direct submissions through OpenReview and an ARR commitment route, subject to NAACL policy. The submission link, formatting requirements, and page limits will be published with the final call for papers.

Can I participate remotely?

We aim to support broad participation, including remote presentations where venue facilities and policies allow. Participation, accessibility, and registration details will be shared when confirmed.
