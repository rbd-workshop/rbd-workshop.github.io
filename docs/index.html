First Workshop at NAACL 2027

Retrieval Beyond Documents

Capability Retrieval for Language Agents

San Francisco, California · Workshop date to be announced

Overview

Retrieval Beyond Documents (RBD) studies how language agents select the resources they need to carry out a task. Alongside documents and passages that supply information, agents may need tools, reusable skills and workflows, memories, models, or other agents. We call this capability retrieval: selecting a resource, or a compatible set of resources, for a goal expressed in natural language and the agent’s current state.

Relevance depends on what a resource can do, whether it is usable in the current context, and how it works with other resources. Interfaces, dependencies, permissions, cost, reliability, and execution history can all affect the choice. RBD brings together researchers in natural language processing, information retrieval, and agent systems to study how these choices should evolve as a task progresses.

The workshop covers capability representation and indexing, retrieval and routing, selection and composition, and evaluation through downstream use. We are interested in both successful task completion and understanding failures at each stage, from retrieving a capability to incorporating and executing it.
